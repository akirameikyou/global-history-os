COUNCIL PROTOCOL

Shared Language / 共通認識プロトコル

PURPOSE

History OS、 Human OS、 そして将来追加されるあらゆる OS が、 同じ言葉を、 同じ意味で扱うための共通言語を定義する。

Protocol は固定された辞書ではない。 観察と実証によって更新され続ける。

OBSERVATION
観察
現象を、そのまま記録すること。 評価・推測・結論より前に存在する最初の情報。
QUESTION
問い
観察から生まれる疑問。 世界理解は問いから始まる。
CASE
事例
一つの現象を観察した実例。 Case Library の最小単位。
REALITY
現実
実際に起きた出来事。 事実・記録・物理的現象。
PERCEPTION
認識
Reality を、 人・社会・文化・AI が、 どのように理解したか。
MEANING
意味
Reality と Perception の接続によって生まれる理解。 History OS の最終 Layer。
PROTOCOL
共通ルール
複数の Case に共通して現れる構造。 採用後は各OSで利用される。
IMPLEMENTATION
実装
Protocol を History OS や Human OS に組み込むこと。
