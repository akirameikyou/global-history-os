## 何を見せるか（優先順位）
1. **開祖の生涯の拠点**（青）：年とともに田辺→北海道→綾部→モンゴル→東京→岩間と灯っていく。
2. **合氣道が世界へ広がる**（ティール）：1950年代から、海外の初の指導・道場の設立が灯る。
3. **現在**：年を最後まで送ると、合気会の海外組織がある85か国が淡く並ぶ。
4. 脇役：右の年表（いまの年の行を強調、先は淡く）、左の世界の出来事（一行ずつ、押すとカード）、紫の用語（押すと語釈）。

## UI の工夫
- 年の帯は1本だけ。上に生涯の出来事の点（青）、下に海外の点（ティール）。帯を押す・なぞると年が動く。
- ‹ › は「次の出来事の年」へ跳ぶ（何も起きない年で止まらない）。▶ は1年ずつ。
- 年の横に、いまの拠点の名（田辺・北海道・綾部・東京・岩間・合気会・本部道場・開祖ののち・世界へ）。
- カードは題・年と場所・本文・「場所を見る」だけ。
- 凡例は3つだけ。
- カメラは「場所を見る」を押した時だけ動く（自転もしない）。選ぶ・年を送るでは動かない。
