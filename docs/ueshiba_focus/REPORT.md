## 何を見せるか（優先順位）
1. **開祖の生涯の拠点**（青）：年とともに田辺→北海道→綾部→モンゴル→東京→岩間と灯っていく。
2. **合氣道が世界へ広がる**（ティール）：1950年代から、海外の初の指導・道場の設立が灯る。
3. **現在**：年を最後まで送ると、合気会の海外組織がある85か国が淡く並ぶ。
4. 脇役：右の年表（いまの年の行を強調、先は淡く）、左の世界の出来事（一行ずつ、押すとカード）、紫の用語（押すと語釈）。

## UI の工夫
- 年の帯は1本だけ。上に生涯の出来事の点（青）、下に海外の点（ティール）。帯を押す・なぞると年が動く。
- ‹ › は「次の出来事の年」へ跳ぶ（何も起きない年で止まらない）。▶ は1年ずつ。
- 年の横に、いまの拠点の名（田辺・北海道・綾部・東京・岩間・合気会・本部道場・開祖ののち・世界へ）。
- カードは題・年と場所・本文・「場所を見る」だけ。
- 凡例は3つだけ。
- カメラは「場所を見る」を押した時だけ動く（自転もしない）。選ぶ・年を送るでは動かない。

## v0.7（2026-11-15）：年譜のカードを厚く、1947年・1961年を調べて直す
- 誕生の行：「和歌山県田辺（現・田辺市元町）に、父・与六、母・ゆきの長男として生まれる。」行は短いまま。
- 年譜の全26項目のカードに「この頃（人と暮らし）」「土地」「時代と世界」を足した。人物の事実はウィキペディア「植芝盛平」（日本語版・英語版、2026-11-15）と合気会の沿革から。両版で食い違うところは日本語版に合わせた（例：上京 1902年春／1901年、惣角との出会い 1915年2月／3月、入植 54戸80余名／85人）。「時代と世界」は同じ年のよく知られた出来事だけで、盛平との因果は書かない。
- 1947年の改組：調べた資料（合気会の沿革日英、ウィキペディア「合気会」日英、Aikido Journal、『植芝盛平伝』による年譜、大阪大学の論文）はどれも1948年。1947年の項を外し、1948年「2月9日、皇武会を改組し、財団法人合気会として文部省の認可を受ける」に一つにした。年譜は27→26項目。
- 1961年のハワイ：渡布（2月末、3月12日にホノルル合気道場の落成式、オアフ・マウイ・ハワイ島で演武と講習、生涯ただ一度の訪米）は Aikido Journal とハワイの合気会の記念誌で確かめた。「第1回演武大会」は確かめられず（第1回は1960年5月14日の東京・山野ホール）、外した。「招かれて」も一次資料が無いので使わない。地点の説明・海外への広がりの注記も同じく直した。
- カードは年代バーの上で止め、長い時はカードの中で送る。
- 海外の道場の設立年は、清水さんが各道場にメールで確かめる予定。それまでは今のまま。

## v0.8（2026-11-15）：生涯の拠点をピンポイントに、滞在と移動を分ける
- 生涯の拠点の印を、地球の上の大きさの円柱から、画面の上で一定の大きさの小さな印（HTML）に替えた。寄るほど位置が正確に見える。いまいる所＝明るく大きめ（10px）、去った所＝淡く小さく（6px）。
- 日本の地点の座標を直した（OSM Nominatim・国土地理院の住所検索・ウィキペディア）：田辺＝元町の町域（生家そのものの位置ではない）、白滝＝上白滝（紀州団体の入植地、顕彰碑のある所）、綾部＝大本本部（長生殿）、東京は二つに分けた＝芝白金（いまの白金台あたり、おおよそ）1927–30／若松町の本部道場 1931–、岩間＝合気神社。
- 滞在の並び（data/ueshiba_places.js の ueshibaStays）：田辺 1883–1911 → 白滝 1912–18 → 綾部 1919–26（1924 モンゴルへの旅）→ 芝白金 1927–30 → 若松町 1931–41 → 岩間 1942–53 → 若松町 1954–69（1961 ハワイへの旅）。戦後の拠点が東京へ戻る年（1954年頃）はウィキペディア日本語版の「合気会の本部を岩間から東京へ移した」による。
- 移動の線：これまでの移動は淡い破線、その年の移動だけ明るい実線。旅は行きの線をその年に、帰りの線を翌年から。
- 右の「今の場所」も滞在の並びから（例「岩間 ・ 滞在 1942–1953」「ハワイ ・ 1961年の旅」）。
- 海外の点（モンゴル・ハワイ・海外への広がり）は仮置きのまま。モンゴルの点はいまウランバートルにあるが、資料（ウィキペディア）では一行が捕らえられたのは内モンゴルのパインタラ（いまの通遼）付近。直すかは清水さんの判断待ち。
- 追記：清水さんの決定で、モンゴルの点をウランバートルから内モンゴルの通遼（パインタラ）へ移した（43.6203, 122.2500、通遼市の中心。白音太拉そのものの点は見つからなかった）。題も「内モンゴル・通遼（パインタラ）」に。
