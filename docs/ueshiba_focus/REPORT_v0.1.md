### カメラ
- 最初に日本へ向けた後は、**「場所を見る」（カードの下のボタン）を押した時だけ動く。** 年譜の行・年代バーの点・地球の印・‹ › ・▶・章のどれを押しても動かない。
- 万次郎版と違い、**地球の自転（autoRotate）もしない**（規則「カメラは押したときだけ動く」に合わせた）。
- 確かめ：年譜の行を押す・年を送る → `pointOfView` が変わらない（37, 138, 1.9）。「場所を見る」→ 本部道場の地（35.70, 139.72, 0.9）へ動く。
- 注意：アプリ内ブラウザの枠が隠れている間は描画が止まるため、そのあいだ押した「場所を見る」は地球が回らない（画面の誤りではなく確かめ方の問題。枠を出して確かめ直した）。

## 4. 実装して感じたこと（共通 Shell に乗せやすかった点・無理があった点）

**乗せやすかった**
- 画面の並びと見た目の約束（CSS・色の意味・浮遊カード・年代バーの描き方・ドラッグとパン・章の札）は、そのまま写して使えた。年譜の行→年へ移る→カード、という流れも同じ形で済んだ。
- 「年カーソル ≠ 年代バー ≠ カメラ」の原則と、カメラを動かす関数を一つ（goToPlace）にする作りは、植芝版の規則にそのまま合った。
- 左上の2枠は「主人公の外の流れ」を置く場所として汎用だった。万次郎版の WORLD EVENTS／W-LINK の位置に、合気会の歩み／未確認を置けた。

**無理があった（共通 Shell を「部品」として使えなかった）**
- `manjiro/focusShell.html` は1枚の HTML に CSS と 1800 行の script が入っていて、航路（track_engine.js）・月の送り（play_steps.js）・W-LINK・P-LINK・自動鑑賞が互いに結びついている。植芝版はそのどれも使わないので、**script は写せず、同じ形で書き直した**（約300行）。CSS だけは写したので、使わない規則が残っている。
- `play_steps.js` の `nextStep` は航路（tracks）を前提にしていて、航路の無い人物には「1年送り」しか残らない。`life_steps.js` に年単位の小さな版を作った。
- 万次郎版の「自転」は通常の表示で動くので、「押したときだけ動く」の規則とは合わない。植芝版では止めた。共通の約束にするなら、どちらにするかを決める必要がある。
- 出来事の「題」が無いデータ（合気会のページは年と一文の形）なので、カードの題に本文をそのまま出した。短い題を作ると出典に無い言い換えを足すことになるため。
- 次に3人目・4人目を載せるなら、共通にできるのは「CSS・カード・年代バーの描画・章メニュー・カメラの関数」。これらを別ファイルの部品に切り出すと、人物ごとの差（航路の有無・送りの単位・左の枠の中身）だけを書けば済む。ただし共通部品に手を入れることになるので、今回はしていない（依頼どおり、そこで止める）。
