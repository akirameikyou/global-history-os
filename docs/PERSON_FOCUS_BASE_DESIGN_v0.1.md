# History OS 基本型「人物フォーカス」設計 v0.1（Claude Code, 2026-11-04）

ブランチ `feature/person-focus-base`（main 1b19322 から。上流なし＝push しない）。清水さんの方針（11/4）：
> 人物を年鑑で選ぶと、北斎フォーカスのように、その人物を主軸に各要素が展開する。人物によって特化するポイントは違うので、どこを抽出するかは個性化される。地域（地球）・年代バー・フォーカスなど基本設計を流用し、人物対応表を反映する。

これは 7/2 に決めた「Focus Person Platform」（右パネルと年代バーをデータで切り替える）の実装でもある。

## 1. 二層にする：共通の基本型 ＋ 人物ごとの特化
| 層 | 中身 | 誰にでも出る？ |
|---|---|---|
| **基本型** | 地球（生まれた所・亡くなった所）／年代バー（その人の生涯）／FOCUS PERSON（名前・年・年齢・分野・番号）／同時代の人（人物対応表の「生きていた・判定できない」） | 基本人物 644 人すべて |
| **特化** | その人だけのデータ（北斎＝画号・P-LINK・世界の同時代画家・作品・年譜） | データがある人だけ |

- 基本型は**データから自動で作る**。手で書くのは特化だけ。
- 特化があるかどうかは `profiles`（人物番号 → 特化データの取り出し方）で決める。最初は北斎 1 人。特化の無い人の画面にも空の欄は出さない（「まだありません」は出さず、欄ごと出さない）。
- 北斎の詳しい版（`hokusai/`、公開中）はそのまま残し、基本型からリンクする。基本型は北斎Focus を置き換えない。

## 2. 人物の番号（hokusai_link の LINK_SPEC §1・§4b を引き継ぐ）
- 内部番号 `base_id`（b0384）を主にし、Wikidata の QID（Q5586）は照合用。URL は `person/?p=b0384`。
- 特化データ側の人物（北斎の P-LINK の勝川春章など）には、基本人物にいれば `base_id` を付け、いなければ独自の番号のまま。**名前の一致だけで自動で結ばない。**

## 3. 同時代の人（判定は hokusai_link の LINK_SPEC §2 と同じ）
- 年代バーの年（NOW）に「生きていた」人／「判定できない」人を別々に数え、足さない。
- 地球には「生きていた」人の生まれた所を小さく出す。**同じ年に生きていたことは関係を意味しない**と画面に書く。

## 4. 場所のデータ
- 基本人物の生まれた所・亡くなった所は Wikidata（P19・P20 と、その場所の座標 P625）から取る。取れない人は地球に点を出さない（推して置かない）。
- 紹介文は Wikidata の日本語の説明（無ければ英語）。AI が書いた紹介文（基本人物の `why`）はこの画面に出さない（未検証のため）。

## 5. 流用するもの・しないもの
- 流用：北斎Focus の画面の文法（全面の地球＋浮遊パネル、上中央の題、右の FOCUS PERSON、下の年代バー、シアン基調、スクロールバーに背景なし）、時間位置と地図カメラの分離（NOW を動かしてもカメラは動かさない）。
- しない：focusShell.html の改造（北斎の公開版を壊さない）。基本型は新しいファイル `person/index.html` として横に置く。共通部分の切り出し（Core 化）は、基本型が 2〜3 人で形になってから相談する。

## 6. 公開について
- `global-history-os` は公開リポジトリ。基本人物のデータ（人物年鑑の作業フォルダは private）をここへ入れることは、**push 前に清水さんの判断が要る**。このブランチはローカルのみ。

## 7. 追加（11/4 清水さんの意見を受けて）
### 7-1. 生まれた所と亡くなった所を線で結ばない
- 弧は「移動の線」に見え、近い所（北斎の本所と浅草）では読めない。生涯は一本線ではない（万次郎）。
- 地球に常に出すのは**生まれた所だけ**。没地はカードの「没」を押したときだけ印を出してそこへ回る（明示した二つ目の操作。北斎Focus の原則と同じ）。

### 7-2. 同時代の人を帯で並べる
- 年代バーの「同時代を帯で並べる」で上へ広がり、その年に生きていた人の生涯を、本人の帯と同じ目盛り・同じ NOW の線で並べる（初期の年表リストの見方）。P-LINK の人は紫。押すと選ぶ。

### 7-3. 同じ年の出来事（交点）
- 出典：Wikidata の人物の主な出来事（P793）・主な作品（P800）と、その年（出来事＝P585/P580、作品＝刊行 P577／制作 P571）。`base_persons_001/fetch_events.py` → `tools/person_focus/build_base_events.py` → `data/base_events.js`。
- **年まで分かるものだけ**（十年・世紀単位は「同じ年」と言えない。例：北斎漫画 1900＝「19世紀」、富嶽三十六景 1830＝十年単位は入らない）。
- 作品の年は**刊行か制作かを画面に書く**（エリーゼのために 1867＝没後の刊行）。亡くなった人の没後の刊行は「同じ年」に入れない。
- 人物の項目に無い出来事（ビーグル号の出航 1831）は、**出来事そのものの Wikidata 項目を指定する「手で選ぶ交点」**（`tools/person_focus/curated_moments.json`）。表示名と選んだ理由は手書き、年と場所は必ず Wikidata から読む。場所が複数ある項目（航海）は 1 点に置かない。
- 画面：左上「この年の出来事」（出典リンク WD つき）／地球＝場所の分かる出来事だけ琥珀の点／年代バー＝同時代の人に出来事がある年の印／帯＝各人の出来事の年の刻み（NOW の年は明るく）。
- 数（11/4）：Wikidata から 1466 件 → 年まで分かる 807 件（239 人）。年なし 510・年が粗い 147 を除いた。手で選ぶ交点 1 件。

### 7-4. 交点をみんなで選ぶ（11/4、スタジオ CASE-20261104-002-p38z7o）
- 基準：**共通性と意外性の両方**（共通性だけなら当たり前、意外性だけならこじつけ）。ビーグル号を選んだ理由を清水さんに問われて言葉になった基準。
- 手順：①北斎の節目の年（1814・1831・1834・1842・1849）について GPT・Gemini・Meta に候補を挙げてもらう（自信がなければ「うろ覚え」と書く）→ ②Claude が Wikidata で年・項目を確かめる → ③通ったものだけ `curated_moments.json` に入れ、**選んだ AI（chosen_by）と理由（why）を残す**。通らなかったものも `rejected` に理由つきで残す。
- 人物は手で書かない：作品は作者（P50・P170）、人物の死は項目そのもの（P570）から Wikidata で読む。基本人物にいれば QID で結び、いなければ「基本人物の外」として出す。人物なしの出来事（南京条約）は「世界の出来事」。
- 作品の項目の P276 は「今ある場所」（ゴヤの絵＝プラド美術館）なので、場所に使わない。
- 結果：候補 26 件（GPT 8・Gemini 8・Meta 10）→ 採用 9 件＋ビーグル号＝10 件、見送り 8 種。3 者がそろって挙げたのはユゴー『ノートルダム・ド・パリ』（1831）とバベッジの解析機関（1834）。解析機関は Wikidata が 1833 なので見送った（多数決より出典）。1834 は今回、通る交点がなかった。
- 自動の出来事のうち、名前（日本語・英語）が無い項目は番号のまま出さない（3 件を除いた）。
