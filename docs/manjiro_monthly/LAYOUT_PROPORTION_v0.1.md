# 画面の配置と比率 v0.1（万次郎 新装版 focusShell）

2026-11-11。清水さんの依頼：北斎版で浮世絵を幾何学的に見たように、History OS の画面の各部の配置も「美しく収まる比率」を前提に考える。機能がぶつかる時は、優先順位は固定しない。

北斎版の幾何ガイド（`hokusai/geometry_guide.js`）と同じ道具立て（対角線・中心線・三分割・黄金比・正方形）で、画面を「1枚の絵」として測る。観察と設計の補助であり、唯一の正解ではない。

## 1. 今の寸法（1280×720 で測った値）

| 部分 | 位置（左, 上, 右, 下） | 大きさ |
|---|---|---|
| 外の余白 | 左右 24px・上 104px（題の下）・下 30px（凡例の上） | |
| 左の列（World Events・W-LINK） | 24, 104, 294, 644 | 幅 270 |
| 右の列（人物・年譜） | 916, 104, 1256, 494 | 幅 340 |
| 中央（地球の場） | 294〜916 | 幅 622 |
| 年代バー | 388, 506, 892, 690 | 幅 504・中心 x=640（画面の中心） |
| W-LINK ボタン | 24, 660, 85, 690 | |
| P-LINK | 916, 648, 1256, 690 | |

観察したこと：
- 右の列 ÷ 左の列 ＝ 340 ÷ 270 ＝ 1.26。ほぼ √φ（1.272）。意図した値ではないが、近い。
- 年代バーは画面の中心線（x=640）の上にある（11/10 に中央へ移した）。
- 下の端：W-LINK ボタン・年代バー・P-LINK の下の端が、みな y=690 に揃っている（今回揃えた）。

## 2. 今回あてた比率（2026-11-11 実装）

- **左の列の高さを 1 : φ に分ける**。使える高さ（上 104px から W-LINK ボタンの上 16px まで）から間 16px を引き、World Events : W-LINK ＝ 1 : 1.618。1280×720 で 200 : 324、1440×900 で 269 : 435、1920×1000 で 307 : 497。
  - 中身の件数では変えない（年代を動かしても枠がせり上がらない）。W-LINK を切っても World Events の大きさは変えない。
  - 一覧は送りのバーの幅を常に取っておく（`scrollbar-gutter: stable`）。出る・消えるで改行が変わらない。
- **左の列を下まで伸ばす**。年代バーを中央に移して左下が空いたので、年代バーが横に重ならない幅では W-LINK ボタンの上まで使う（1280×720 で高さ 390 → 540）。年代バーが左の列の下まで来る幅（約 1200px 未満）では、今までどおり年代バーの上まで。
- **間の寸法**：2つの枠の間・枠と W-LINK ボタンの間を 16px（外の余白 24px の 2/3）に揃えた。

## 3. 自動鑑賞の視線の設計（今回の置き分け）

| | 章の表紙 | 出来事のカード |
|---|---|---|
| 役目 | 場面の転換（章ごとに1回） | 中身（何度も出る） |
| 置き場所 | 画面の上の中央（視線の入口）。地球の上部に大きく | 年月の大きな数字のすぐ上（西暦と見出しを近くに） |
| 情報量 | 章の題・年・一行 | 題・年月と場所・最初の1文・確かさの札 |
| 時間 | 4秒（地球が新しい地域へ向きを変える間） | 4〜7秒（文字数から） |
| 演出 | 動きは出る時だけ | 表示時間の線は付けない（読む視線を奪うので外した） |

確かさ：黄色の一文は目立ちすぎるので「詳しく」の先頭へ移した。カードの年月の行の横には、破線の小さな札（例「年のみ・月は推測」）だけを出す。破線は凡例の「破線＝推定」と同じ記号。記録どおりの時は札を出さない。

## 4. まだあてていない比率（案。清水さんの判断待ち）

1. **左右の列の幅**：270 と 340 を、φ（270 : 437）か √φ（270 : 343、今とほぼ同じ）のどちらで決めるか。今は √φ に近いので、そのまま √φ と名付けて固定する案が軽い。
2. **地球の中心の高さ**：自動鑑賞の間、カードの置き場所を空けるために地球を上へずらしている（1280×720 で 128px）。そのため地球が題字に掛かる。案：ずらす量を、地球の中心が画面の上から 1/φ²（0.382）の高さに来るところで止める。または、題字を自動鑑賞の間だけ薄くする。
3. **縦の分け方**：年代バーの上の端（y=506）は、題の下から凡例の上までの帯（104〜690）を 2.2 : 1 に分けている。φ²（2.618 : 1）にするなら年代バーの上の端は約 528 になる。年代バーの高さを詰める必要があるので、見た目を見てから決める。
4. **641〜1199px の幅**：年代バーが左の列の下まで来る幅は、まだ比率で詰めていない。
